# Report on LabWork#5
*LUP-розклад для системи лінійних рівнянь*

Для виконання поставленого завдання спочатку створюємо два класи: Вектор та Матриця (в моєму випадку квадратна).

*Клас Vector:* Використовуємо для зберігання одновимірного масиву даних, а саме правої частини рівняння b та вектора невідомих змінних.

*Клас Matrix:* Власне створений для роботи з квадратними матрицями коефіцієнтів системи. Для цього класу виконуємо перевантаження опреаторів +, * (на матрицю/ на вектор) для коректного виконання операцій над матрицями. Також ми можемо створити звичайну одиничну матрицю для ініціалізації розкладу за допомогою статичного методу identity.

Далі маємо *клас LUPMethod* для самого розв'язання системи. Він розкладає отриману на вхід матрицю на нижню трикутну (L), верхню трикутну (U) та вектор перестановок (P) таким чином, що PA=LU. Потім розв'язує систему Ly=Pb, а після неї - Ux=y. Також тут виконується перевірка матриці на невиродженість, адже ми не можемо отримати один єдиний вірний розв'язок з виродженої матриці (в такому випадку їх або безліч, або взагалі немає).

Загалом програма знаходить правильний розв'язок, хоча для великих систем інколи виникали дрібні похибки. Щоб цього уникнути, у методі виводу класу Vector виконуємо округлення неістотно малих значень (як -1.03251e-14).
